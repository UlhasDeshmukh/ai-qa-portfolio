# P2 — LLM-as-a-Judge Pipeline

A 10-question golden dataset with human-written ideal answers, graded two ways:

- Human rubric score
- LLM-as-a-Judge score, using the same rubric

Compares where the two disagree and why, and documents any judge self-preference bias observed.

Corresponds to Module 5 (AI Evaluation Metrics & Manual AI Testing) in the Field Manual.
