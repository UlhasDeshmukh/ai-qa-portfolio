## Getting Started

### Prerequisites

- Python 3.8+
- Node.js 16+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd ai-qa-portfolio

# Install Python dependencies (when available)
pip install -r requirements.txt

# Install TypeScript/Node dependencies (when available)
npm install
```
