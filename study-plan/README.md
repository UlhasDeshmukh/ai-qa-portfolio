# AI-QA Study Plan (portable, offline copy)

This folder is a self-contained, offline copy of the study plan — put here so it's tied to this repo (your personal GitHub account), not to any particular Claude account or machine. Clone this repo on any laptop and everything works with no login.

- **`field-manual.html`** — the full course: lesson content, diagrams, quizzes, module map. Open it directly in any browser (double-click, or `open field-manual.html`).
- **`exercises.html`** — step-by-step hands-on labs for every module, cross-linked from the Field Manual.
- **`AI-QA-Master-Study-Plan.md`** — the same content as plain Markdown, for reading/editing in an editor or Claude Code.

## Important: progress tracking is per-browser, per-device

The checkboxes, quiz answers, and Bug Board entries in the two HTML pages save to that browser's `localStorage` — tied to *that specific browser on that specific device*. Opening these files:
- on a different laptop,
- in a different browser,
- or via a different hosting (e.g. the original claude.ai-hosted versions vs. this local copy),

...starts that tracking fresh each time. There's no syncing between copies. If you want a single continuously-updated version, pick one place to always open it from (e.g. always this repo's local files, or always the claude.ai links) rather than switching between them.

## Keeping this copy in sync

This is a snapshot. If you ask Claude to update the study plan again later, re-export the updated files here (or ask it to do so) and commit the change, the same way you would for any other file in this repo.
